# Aurora Student Lab — Veda Technology Task 7

## Student Information Dictionary

A polished terminal-run web application for Veda Technology Task 7. The backend uses a **Python dictionary** with a unique Student ID as the key. The web interface provides search, add, update and delete operations and saves records in `students.json`.

## Task requirements covered
- Python dictionary for structured student information
- Unique Student ID keys
- Search student records
- Add student records
- Update student records
- Example outputs / sample data
- Persistent local data in `students.json`

## Tools
- Python
- HTML
- CSS
- JavaScript

No Jupyter Notebook, Flask, pip install, Node.js or database setup is required.

## Run from PowerShell

Open PowerShell and run these commands exactly:

```powershell
cd "D:\veda technology\student-information-dictionary-task7-veda-pro"
py app.py
```

Then open:

```text
http://127.0.0.1:8000
```

### Important when using an older Task 7 version
Stop any older server first with `Ctrl + C`. Then close the old browser tab and start this version from the **`student-information-dictionary-task7-veda-pro`** folder. This version serves `index.html`, `styles.css`, and `script.js` from the Python server so the complete design loads correctly.
